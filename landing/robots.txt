# /unsubscribe is deliberately NOT disallowed, despite being a page nobody should
# arrive at from a search result. It carries <meta name="robots" content="noindex">,
# and a crawler that is forbidden to fetch the page never reads that tag — the URL can
# then still be listed, bare and snippet-less, which is the outcome the tag exists to
# prevent. Blocking the crawl and asking for noindex are mutually exclusive; the tag is
# the one that actually removes a page, so it wins and the crawl is allowed.
#
# /login and /register are not here either: they are on saas.turboplm.com, and robots.txt
# only governs the host that serves it, so naming them here did nothing at all. That host
# sends X-Robots-Tag: noindex, nofollow on everything, set by its Cloudflare Worker.
